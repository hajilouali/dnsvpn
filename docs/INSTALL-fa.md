# راهنمای نصب سرور dnsvpn (فارسی)

این پروژه یک VPN است که داده‌اش روی DNS (پورت ۵۳) جابه‌جا می‌شود؛ مناسب مواقعی که
اینترنت معمولی بسته است ولی DNS و پورت ۵۳ کار می‌کنند. سرعت بیشتر از تونل‌های DNS
معمولی، چون کلاینت هم‌زمان از چندین resolver استفاده می‌کند و خودش resolverهای سالم و
سریع را پیدا و تأیید می‌کند.

## پیش‌نیازها

- یک سرور (VPS) خارج از کشور که پورت ۵۳ (UDP) رویش باز باشد و به کاربران نزدیک باشد.
- یک دامنه که DNS آن دست خودت است تا یک زیر‌دامنه را به سرور واگذار کنی.

## گام ۱: واگذاری زیر‌دامنه‌ی تونل

یک زیر‌دامنه‌ی کوتاه انتخاب کن، مثلاً `t.example.com`. در پنل DNS دامنه این دو رکورد را بساز
(به‌جای `example.com` و `SERVER_IP` مقدار خودت):

| نوع | نام   | مقدار               | توضیح                         |
|-----|-------|---------------------|-------------------------------|
| A   | `ns1` | `SERVER_IP`         | حتماً DNS only (بدون پروکسی/ابر)|
| NS  | `t`   | `ns1.example.com.`  | واگذاری `t.example.com`        |

هرچه زیر‌دامنه کوتاه‌تر باشد، داده‌ی بیشتری در هر query جا می‌شود.

## گام ۲: نصب سرور

روی یک سرور تازه‌ی اوبونتو/دبیان، با کاربر root:

```bash
curl -fsSL https://raw.githubusercontent.com/hajilouali/dnsvpn/main/deploy/install.sh -o install.sh
chmod +x install.sh
sudo ./install.sh --zone t.example.com
```

اسکریپت خودش: باینری سرور را دانلود می‌کند، پورت ۵۳ را آزاد می‌کند (استاب
systemd-resolved را خاموش می‌کند)، یک PSK و رمز ادمین می‌سازد، سرویس systemd نصب می‌کند و
در پایان رکوردهای DNS، مقدار PSK و آدرس پنل را چاپ می‌کند.

مشاهده‌ی لاگ: `journalctl -u dnsvpn -f`
توقف/شروع: `systemctl stop|start|restart dnsvpn`

## گام ۳: مدیریت کاربران

به‌طور پیش‌فرض پنل فقط روی `127.0.0.1:8080` (localhost) است. از طریق تونل SSH بازش کن:

```bash
ssh -L 8088:127.0.0.1:8080 you@SERVER_IP
# بعد در مرورگر: http://127.0.0.1:8088  (کاربر: admin، رمز: از خروجی نصب)
```

**دسترسی عمومی با HTTPS (اختیاری):** اگر می‌خواهی مستقیم در مرورگر و بدون SSH باز باشد، موقع
نصب `--panel-domain panel.example.com` بده (یا در env مقدار `PANEL_DOMAIN`). یک رکورد A برای آن
دامنه به IP سرور بزن و پورت‌های ۸۰ و ۴۴۳ را باز کن؛ سرور خودش گواهی Let’s Encrypt می‌گیرد و پنل
را روی `https://panel.example.com` سرو می‌کند. (یادآوری: چون IP سرور از ایران بلاک است، دسترسی
از داخل ایران بدون پروکسی کار نمی‌کند.)

**تغییر رمز ادمین:** از دکمه‌ی «Change password» بالای پنل. رمزِ نصب فقط «بذرِ» اولیه است؛ رمز
واقعی به‌صورت هش‌شده در دیتابیس ذخیره می‌شود و بعد از تغییر، پس از ری‌استارت هم باقی می‌ماند.

برای هر کاربر یک **token** بساز و محدودیت‌هایش را بگذار (حجم، انقضا، تعداد اتصال هم‌زمان).
هر کلاینت به سه چیز نیاز دارد: **zone**، **PSK**، و **token** خودش.

**لینک کانفیگ / QR:** جلوی هر کاربر دکمه‌ی **Config** هست که یک لینک `dnsvpn://…` و یک QR
نشان می‌دهد که zone/psk/token و رنج‌های resolver را یک‌جا دارد. لینک را از هر راهی برای
کاربر بفرست؛ بدون نیاز به شبکه import می‌شود (پس قبل از قطعی هم می‌شود ست کرد):

- **اندروید:** روی لینک بزن، یا QR را اسکن کن، یا با دکمه‌ی «Import link from clipboard» از
  کلیپ‌بورد paste کن.
- **دسکتاپ:** `dnsvpn-client -link "dnsvpn://…"`.

رنج‌های پیش‌فرضِ داخلِ لینک‌ها را با فلگ `-candidates` سرور تعیین کن (در فایل
`/etc/dnsvpn/dnsvpn.env` مقدار `CANDIDATES=`)، مثلاً `2.188.21.0/24,178.22.122.100`.

## گام ۴: کلاینت

از صفحه‌ی [Releases](https://github.com/hajilouali/dnsvpn/releases) کلاینت را
بردار. یک `config.json` کنارش بگذار (zone/psk/token را پر کن) و اجرا کن؛ بعد پروکسی
مرورگر را روی SOCKS5 با آدرس `127.0.0.1:1080` بگذار. جزئیات در README اصلی.

**نکته‌ی سرعت:** کلاینت را روی همان شبکه‌ای اجرا کن که کاربر واقعاً آنجاست (تا resolver
خودِ ISP نزدیک باشد) و رنج‌های resolver آن ISP را در `candidates` اضافه کن (به شکل CIDR
مثل `2.188.21.0/24`). هرچه resolverهای سالمِ نزدیک‌تری پیدا شود، سرعت جمع بیشتر می‌شود.

## حذف نصب

```bash
sudo ./deploy/uninstall.sh
```
